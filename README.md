# Lab2Web — Praktikum 2 HTML Lanjutan

Proyek praktikum HTML lanjutan yang berisi tabel mahasiswa, form registrasi, semantic HTML, validasi form, dan elemen multimedia.

## File Proyek

- `index.html` — halaman latihan awal.
- `biodata.html` — halaman biodata mahasiswa.
- `media/` — tempat menyimpan file multimedia.
- `screenshots/` — dokumentasi hasil praktikum.

## Cara Menjalankan

1. Buka folder proyek di Visual Studio Code.
2. Buka `biodata.html` menggunakan browser atau ekstensi Live Server.
3. Untuk menampilkan banner, simpan file `Banner.gif` ke folder `media/`.
4. Untuk mencoba video, simpan file `video.mp4` ke folder `media/`.

## Materi yang Dipraktikkan

- Tabel menggunakan `table`, `caption`, `thead`, `tbody`, `tfoot`, `th`, `td`, dan `colspan`.
- Form menggunakan `input`, `label`, `radio`, `checkbox`, `select`, `textarea`, serta tombol submit dan reset.
- Semantic HTML menggunakan `header`, `nav`, `main`, `section`, `aside`, dan `footer`.
- Validasi dasar menggunakan `required`, `minlength`, `min`, `max`, dan tipe input seperti `email`, `date`, serta `number`.
- Multimedia menggunakan elemen `video`.

> Catatan: form ini merupakan latihan HTML. Data belum disimpan ke database atau dikirim ke server.
